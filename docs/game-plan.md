# 經濟知識王：Supply and Demand 遊戲企劃書

版本：企劃草案 0.1  
目標平台：Phaser 4 網頁遊戲，優先支援學生手機與教室投影畫面  
企劃依據：目前已確認的需求；未定數值會標示為「建議初值」

## 一、遊戲概念

玩家在知識競賽節目風格的介面中回答經濟學選擇題，學習供給、需求與均衡。玩家可以單人挑戰電腦、參加全班即時連線競賽，或進入自由練習。答對越快分數越高，連續答對可獲得加成；競賽結束後依成績排名並結算智慧金幣。

單人和全班競賽提供比賽節奏與排名；自由練習提供立即解析。競賽模式在整場結束後整理每題正解與圖表解析。

## 二、目標玩家與學習目標

- 主要玩家：高職生。
- 使用情境：教師在課堂導入經濟學，學生使用手機作答；全班競賽由教師建立遊戲房間，並可將主持畫面投影。
- 第一版學習主題：供給與需求均衡。
- 玩家完成練習後應能：
  1. 從供需圖讀出均衡價格與均衡數量。
  2. 判斷供給或需求改變後，均衡價格與數量的變化方向。
  3. 分辨供需曲線移動與沿著曲線移動。

## 三、遊戲模式

| 模式 | 玩法 | 回饋與獎勵 |
| --- | --- | --- |
| 單人對電腦 | 玩家與模擬真人的電腦對手回答相同題目。電腦在作答時間內選擇答案，並依難度調整反應速度與答對率。 | 比賽結束後比較總分並查看逐題解析。建議勝利後由系統發放金幣。 |
| 全班連線競賽 | 教師建立房間並顯示加入代碼；學生用手機輸入暱稱加入。全班同步回答相同題目，結束後依總分排名。 | 主持畫面可投影題目與排行榜；結束後提供逐題解析與金幣結算。 |
| 自由練習 | 玩家自行選擇難度，不限時作答。 | 每題作答後立即顯示正解和解析，不計競賽勝負、不發金幣。 |

## 四、題目難度與比賽節奏

以下題數與單題時間依玩家提供的設定：

| 難度 | 題數 | 每題作答時間 | 建議題型 |
| --- | ---: | ---: | --- |
| 簡單 | 25 題 | 20 秒 | 看供需圖辨認交點，讀出均衡價格與數量。 |
| 適中 | 20 題 | 25 秒 | 判斷單一供給或需求曲線移動後，均衡價格與數量如何改變。 |
| 困難 | 10 題 | 30 秒 | 解讀較複雜的情境，或判斷供需同時變動時的均衡結果。 |

競賽模式使用上述題數和時間；自由練習不限時。圖表題以可縮放的向量圖或程式繪製，確保手機和投影畫面都清晰。

## 五、核心遊戲規則

### 作答與計分

- 每題提供選擇題選項；玩家和對手在相同題目與時限內各自作答。
- 答對可得基本分，剩餘時間越多，速度加分越高。
- 連續答對提高分數倍率；答錯或逾時會中斷連勝。
- 建議初始計分：答對基本分 500 分，加上依剩餘時間計算、最高 500 分的速度分；連勝每題增加 10% 倍率，最高 2 倍。此數值需在課堂試玩後調整。
- 全場題目結束後，以總分決定勝負或名次；同分時建議依答對題數，再依平均作答時間排序。

### 道具

玩家確認第一版包含提示、延長時間、分數加倍、答錯修正，並保留多人模式的防偷道具。

| 道具 | 建議效果 |
| --- | --- |
| 提示 | 移除兩個錯誤選項，協助玩家聚焦判斷。 |
| 延長時間 | 延長個人作答期限 5 秒。連線賽中，已完成作答的玩家先等待；全房間最多多等 5 秒後公布結果。 |
| 分數加倍 | 對下一題答對所得分數加倍。 |
| 答錯修正 | 題目第一次答錯後可再選一次；建議第二次答對取得部分分數，並重置連勝。 |
| 防止金幣被偷 | 在多人賽金幣結算時抵擋一次金幣轉移。 |

道具由金幣購買，並在使用時消耗。單人對電腦可使用前四種道具；防偷道具在多人金幣結算時生效。道具售價、每場使用上限與玩家起始金幣屬於待平衡數值，應透過試玩調整。

### 智慧金幣

- 自由練習不產生金幣。
- 單人對電腦的勝利可獲得系統發放的金幣。
- 全班賽依排名轉移金幣；高名次取得的金額高於低名次。
- 建議初始結算方式：由較低名次玩家各提供最多 1 枚金幣形成獎池，再依排名由前三名以 50%、30%、20% 的比例分配；參賽人數不足三人時只分給實際得獎名次。金額採整數，剩餘金幣優先分配給較高名次。防偷道具可抵擋一次扣款，玩家餘額不會低於零。
- 新玩家的起始金幣需要在實作前定案。建議提供少量起始金幣，讓新玩家能參加第一次金幣轉移並試用商店；這筆金幣屬於開局資產，不是練習獎勵。
- 建議以暱稱加匿名玩家識別碼保存金幣與道具，不要求學生先提供電子郵件等個人資料。跨裝置找回帳戶的方式可在後續階段規劃。

上述獎池比例和起始金額都是企劃建議，需再依班級人數及試玩結果調整。

## 六、單場流程與主要畫面

1. 遊戲直接啟動至模式選擇畫面。
2. 玩家選擇單人對電腦、全班連線競賽或自由練習，再選擇難度。
3. 全班競賽由教師建立房間；學生輸入代碼和暱稱加入，主持畫面顯示玩家名單。
4. 題目同步開始，玩家在手機上選擇答案；電腦模式中的模擬對手也在同一時限內作答。
5. 各題按答題正確性、速度與連勝狀態計分。
6. 全部題目結束後顯示總分、排名、智慧金幣結算，以及每題正解和供需圖表解析。
7. 玩家可回到模式選單，或前往金幣商店購買道具。

## 七、視覺與素材方向

- 整體方向：知識競賽節目感，使用 Kenney 素材作為介面基礎。
- 已選 Kenney UI Pack 作為主要按鈕素材，使用藍、紅、綠、黃四種色版做選項按鈕，並選用勾叉、連勝星星與進度條素材。
- 已選 Kenney Board Game Icons 作為輔助圖示，包含代幣、皇冠、沙漏、盾牌、開書、回復箭頭與金幣轉移圖示。
- 供需曲線、座標軸、均衡點標記、金幣外觀及競賽舞台背景以 Phaser 圖形繪製，方便依手機與投影畫面調整尺寸與顏色。
- 繁體中文字型使用系統字型 fallback：Noto Sans TC、PingFang TC、Microsoft JhengHei，再退回 sans-serif；目前不額外下載 Kenney 字型。
- 原始素材包、授權檔與來源雜湊保存在 assets/downloads；挑選後的執行素材放在 assets/images/kenney-ui-pack 與 assets/images/kenney-board-game-icons。
- 完整選取清單與授權記錄見 docs/asset-selection.md 和 ASSET-CREDITS.md。

## 八、實作步驟

使用 Phaser 4.2.1。網站根入口直接載入遊戲；模式選單是遊戲內的第一個畫面。

### 步驟 1：完成素材挑選（已完成）

1. 已檢視 Kenney UI Pack 與 Board Game Icons 的官方預覽、下載包內容與授權。
2. 已從兩個 CC0 素材包挑選 18 個 PNG 執行素材，並保存原始 ZIP、授權文字與 SHA-256 來源資料。
3. 已決定使用繁體中文字型 fallback，並以 Phaser 圖形繪製供需圖與舞台背景。
4. 素材已整理至 assets/images/kenney-ui-pack 與 assets/images/kenney-board-game-icons。

完成條件：主要介面與輔助圖示已選定並入庫；接著進入 MVP，並在手機與投影畫面中檢視實際縮放和可讀性。

### 步驟 2：完成 MVP

MVP 是可實際走完遊戲流程的最小版本，三種模式都各有可操作的基本流程。為先驗證玩法，可先使用少量經確認的示範題；這個題庫只供 MVP 試玩，完整課堂版本再補足正式題數。

1. 建立遊戲啟動畫面、模式選擇、難度選擇、題目、結果與逐題解析畫面。
2. 建立結構化題庫，存放選項、答案、難度、學習目標、圖表資料及解析。
3. 完成自由練習：不限時、答後立即解析、不發金幣。
4. 完成單人對電腦：同題作答、模擬電腦反應、速度分、連勝加成及勝利金幣。
5. 完成全班連線：教師建立房間、學生手機加入、同題同步計時、即時收集答案、排名與結算。
6. 完成四種單人道具和多人金幣結算用的防偷道具。
7. 建立伺服器端房間狀態與權威計時、計分、排名、金幣轉移；玩家端負責呈現畫面和送出答案。
8. 以多支手機和一個投影主持畫面走完三種模式，確認教室操作流程可理解。

完成條件：玩家能選擇三種模式，成功答題並看到結果；教師能開房間，學生能用手機加入同一場競賽；金幣與道具能正常結算；供需圖在手機上仍可辨識。

### 步驟 3：迭代一，補齊正式題庫與學習解析

1. 補足簡單 25 題、適中 20 題、困難 10 題。
2. 確認每題對應到均衡點計算、供需變動或曲線移動辨識等學習目標。
3. 為競賽結果頁的每題撰寫簡短解析；自由練習則在每題後立即提供解析。
4. 由經濟學教師或課程資料檢視圖表、答案和說明。
5. 調整題目文字、選項干擾項與圖表標示，讓錯誤選項能指出常見迷思。

### 步驟 4：迭代二，平衡競賽、AI 與道具經濟

1. 依試玩結果調整答對基本分、速度加分及連勝倍率。
2. 調整電腦對手在各難度下的答對率與反應時間，使其像真人且有合理挑戰。
3. 調整道具售價、效果、每場使用限制及連線賽延長時間的等待節奏。
4. 觀察金幣是否過度集中，調整名次比例、單場損失上限、起始金額及防偷效果。
5. 確認金幣和道具在不同模式間保存一致，並防止玩家端自行修改結算結果。

### 步驟 5：迭代三，課堂試用與手機體驗完善

1. 在不同手機尺寸與網路狀況下進行課堂試用。
2. 檢查加入代碼、暱稱、重新連線、離開房間和教師開始比賽等流程。
3. 調整主持畫面資訊密度、排行榜更新節奏、計時提示與答案按鈕大小。
4. 根據學生與教師回饋修正題目難度和解析可讀性。
5. 規劃教師題庫管理、課堂結果匯出或更多競賽模式等後續功能。

## 九、建議的程式模組

- src/game/config：遊戲設定、難度、計時和計分參數。
- src/game/scenes：模式選單、房間等待、答題、結果與商店場景。
- src/game/data：題庫、道具定義、金幣與排名規則。
- src/game/systems：計分、連線房間、AI 對手、道具和金幣結算。
- src/game/ui：計時器、選項按鈕、排行榜、金幣與道具介面。
- src/game/utils：圖表座標、格式化和共用工具。
- assets/images：Kenney UI、圖示、背景及角色素材。
- assets/fonts：授權可用且支援繁體中文的字型。

## 十、MVP 之後需確認的設計數值

以下內容目前採建議初值，正式開發前或第一次試玩後再定案：

1. 玩家起始金幣、各道具售價，以及單人勝利獎勵。
2. 全班賽金幣獎池的名次比例、單人最多損失金額和同分處理。
3. 電腦對手各難度的正確率與反應時間範圍。
4. 提示、延長時間、分數加倍、答錯修正的每場使用次數。
5. 暱稱與匿名玩家識別碼如何跨裝置找回。
6. 題庫是否需要對齊指定課本或學校使用的經濟學教材。

## 十一、目前明確的範圍

第一版包含單人對電腦、全班連線競賽、自由練習三種模式；供需均衡為第一個學習主題；素材以 Kenney 為基礎並採知識競賽節目感。課堂競賽使用同步題目，按速度和連續答對計分，結果頁提供解析。金幣用於道具商店，真人連線賽依排名從較低名次向較高名次轉移；防偷道具可抵擋一次轉移。開發順序先完成素材挑選，再完成 MVP，之後分階段擴充內容、平衡機制與完善課堂體驗。
